## [**25m**] 📚 TT: Overview

ACS-3220's README taught the section order we kept: description, prerequisites, specifics, outcomes, schedule, assignments, evaluation, recordings.

What we changed:

- Tokens became SAMPLE values
- Fourteen Docker sessions became five modules over seven weeks
- `Web/sw.js` follows the template whitelist (`cdn.jsdelivr.net`, no `makeschool.com`)
- Images are the SAMPLE badge only — we skipped huge ACS-3220 binaries

If a link is not in `_sidebar.md`, Docsify search will not find it. That is why this module is listed there.
