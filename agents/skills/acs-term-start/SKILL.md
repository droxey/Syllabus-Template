# ACS term start and course plan

## Required first step

1. Read canon: `https://github.com/droxey/Syllabus-Template/blob/master/TERM.md` (or `TERM.md` in the course repo if present).
2. Also use [CALENDAR.md](https://github.com/droxey/Syllabus-Template/blob/master/CALENDAR.md) and [SLACK.md](https://github.com/droxey/Syllabus-Template/blob/master/SLACK.md) for those surfaces.
3. Follow [acs-lesson-plan](sand-workflow:acs-lesson-plan) for lesson Markdown bars.

## Human gates (never skip)

- Content one-pass (outcomes + week topics + README `## Schedule`) → Dani reviews before full lessons.
- Calendar: draft → ask approval **before** create.
- Slack invites: only after Dani hands Ellucian CSV/list.
- Slack/email sends: confirm before send.

## Autonomous OK

- Verify Docsify/Pages live; fix clear breakage.
- Draft missing outcomes/topics/Schedule/OUTLINE (keep existing intact — no prior-term redraft).
- Draft full lessons after OUTLINE exists and content review passed.
- Route prose through Writer AI-writing gate before ready-to-PR.
- Open droxey PRs; do not merge unless Dani says so.

## Order

outcomes → week topics → `## Schedule` (one pass) → `Lessons/OUTLINE.md` (`## Day X - Topic`) → full lessons → sidebar → day-1 launch checks.
