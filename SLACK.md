# Slack Course Channels

Instructor/agent ops for ACS Slack. Not a published syllabus page. Do not link from `_sidebar.md`.

## Channel Naming (Day-1)

Pattern: `#acs-xxxx` where `xxxx` is the **4-digit course code**.

Derive from the repo name prefix:

| Repo | Channel |
| ---- | ------- |
| `Tech-at-DU/ACS-3220-Docker-DevOps-Deployments` | `#acs-3220` |
| `Tech-at-DU/ACS-4210-Strongly-Typed-Languages` | `#acs-4210` |
| `Tech-at-DU/ACS-2951-Engineering-Careers` | `#acs-2951` |

Before day 1: create the channel if needed, then **invite students** to `#acs-xxxx`.

## Channel Map

- `#acs-*` and `#general` — student-facing
- `#faculty-acs` — faculty only (administrators watch — extra care)
- Assume other Slack users are students unless known otherwise (e.g. Mitchell Hudson is faculty)

## Send Guardrails

1. Always confirm with Dani **before any Slack send**.
2. Never discuss grades or scores in Slack.
3. Never put private student feedback in channels.
4. Prefer drafts for Dani to approve when a message leaves under their name.
